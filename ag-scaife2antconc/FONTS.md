# Bundled font

The browser workspace uses the unmodified Gentium Plus Regular 6.101 webfont
for Ancient Greek text, including correction inputs. It supports polytonic Greek
and is served locally; no font installation or external font service is required.

- Upstream: https://github.com/silnrsi/font-gentium/releases/tag/v6.101
- Archive: `GentiumPlus-6.101.zip`
- Original archive member: `GentiumPlus-6.101/web/GentiumPlus-Regular.woff2`
- SHA-256: `0f056cd1ac5462720cf6e6715cc3c9917db9a3afbcd75fa8496742d507cc90fb`
